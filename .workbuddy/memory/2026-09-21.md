### 工具坑（非项目代码问题，避免重犯）
- 用 Python 生成补丁做非交互分离暂存时，`Path.write_text` 默认把 `\n` 转成 CRLF，会导致 `git apply --cached` 失败，必须传 `newline=''`；`subprocess.run` 不接受 `newline` 参数。
- MSYS 路径坑复现：Git Bash 的 `/tmp/x` 与原生 Python 解析的 `E:\tmp\x` 是两个不同文件，跨工具传文件一律用项目内相对路径。
- bash 双引号内的反引号会触发命令替换，含反引号的 grep 模式要改用 Python 或单引号。
