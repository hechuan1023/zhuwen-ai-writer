# 铸文竞品功能盘点与补齐路线

盘点日期：2026-10-25
范围：番茄作家助手、橙瓜码字、Scrivener、Novelcrafter 的公开功能说明，与铸文当前源码对照。竞品功能会随版本变化，本表是方向参考，不是完整功能审计。

## 已有基础

铸文已经具备本地作品/卷章管理、人物与世界观资料库、章节细纲、时间线、伏笔与人物关系、每日目标和统计、专注/编辑器外观、自动备份、历史快照与差异比较、DOCX/TXT/Markdown 导出，以及带引用、上下文预览、流式回复、取消、差异采纳和写作风格卡的 AI 助手。

因此，补齐方向应集中在“写作过程中的结构可视化”和“减少作者手动整理上下文”，而不是再造一套重复的资料表或普通聊天框。

## 对照与差距

| 方向 | 公开产品做法 | 铸文现状 | 建议 |
|---|---|---|---|
| 章节结构规划 | Scrivener 提供 Corkboard 与 Outliner；Novelcrafter 提供可拖放 Grid、场景标签和 Marker Timeline | 已有卷章树、场景拖放规划板、章节状态筛选/修改，以及按章节与手动场景顺序展示的叙事时间线；时间标签原文展示，不自动解释自由文本 | 继续补充场景 POV 标签、可选时间锚点及按正文/场景长度比例缩放的时间线；不把中文相对时间误解析成公历日期 |
| 故事资料与 AI 上下文 | Novelcrafter Codex 宣称支持角色/地点跨稿件提及索引、别名识别、提及时间线与人物/地点进展追踪 | 已有本地候选匹配、逐条确认引用；人物、地点和势力可按全书章节核对提及片段并回链；人物卡可记录作者确认的阶段变化，随人物卡引用进入 AI 上下文。提及索引按章节版本与名称/别名指纹增量重建；字符串匹配仍可能误报，地点/势力的事实有效区间尚缺 | 后续支持地点/势力阶段记录的有效区间与来源章节核验；保留作者确认，不由匹配自动推断状态 |
| 修订与版本安全 | Scrivener 提供文档快照；橙瓜说明提供章节时光机 | 已有章节快照、AI 修改前快照、差异比较和恢复 | 已有能力。后续重点改善历史入口可见性，不重复建设底层版本系统 |
| 专注与码字激励 | 橙瓜公开功能包括专注锁定、目标、统计、自动滚屏等 | 已有专注写作、字数目标、统计、编辑器外观和本地备份 | 已具备主干；可评估按用户反馈增加“定时/字数专注锁”，不做社交排行榜优先项 |
| AI 写作控制 | Novelcrafter 将故事资料、规划与生成结合；Sudowrite 类型工具强调局部改写和创作辅助 | 已有局部润色、续写、引用、风格卡、人工采纳与逐句采纳；细纲可带入起草；回复显示来源并可查看快照/跳回资料编辑器，采纳前核对章节修订和来源资料卡版本；多卡组合支持跨作品复用及 JSON 迁移 | 创作者社区分享和反馈闭环仍待评估；继续增强可解释引用检索与跨章节连续性 |
| 导出与迁移 | Scrivener 的 Compile 支持 DOCX、ePub、Kindle、PDF、Final Draft 等输出；常见中文码字工具支持 DOCX/TXT | 已有 DOCX、TXT、Markdown、EPUB 和完整作品备份；EPUB 含书籍元数据、目录及章节导航，暂不嵌入封面/插图 | 下一步补可配置发布排版模板、封面/插图与导出预览；PDF/Kindle 等按用户需求评估 |

## 本轮实现

- 新增「追更钩子与兑现」「悬疑线索与信息差」「人物声线与关系张力」「轻喜剧与处境错位」四张内置风格卡。
- 这些卡按叙事机制和可执行技法组织，不模仿某位作者的独特表达，也不复刻某本热门作品的句式或专有设定。
- 内置卡会随数据库启动自动补齐；已有内置卡通过版本号升级，自定义卡不覆盖。
- AI 对话菜单条目改为稳定唯一 ID，避免同类快捷任务共用重复标识。
- 统一按钮按压反馈，改善 AI 菜单键盘聚焦、滚动和溢出，并精修输入框焦点、上下文工具按钮与发送按钮状态。
- 打磨共享选择器：统一焦点环、选中态和菜单层次；键盘导航跳过禁用项，补齐活动选项 ARIA 关联，并限制选项滚动不串到背景页面。
- 统一书架、设置、资料编辑与导入导出表单的主题表面：输入框背景、文字、圆角和占位提示改用设计 token，修复暗色主题仍显示浅纸色输入框的问题；按钮 hover 不再覆盖禁用态或危险操作色，减少动效偏好同时作用于表单过渡。
- 新增可视化场景规划板：复用 `library_items.chapter_id` / `sort_order` 和现有章节/分卷，不创建第二套规划数据；支持拖放重新分配章节、保存排序、未安排场景收纳、章节正文跳转和卷筛选。
- 场景规划板接入已有章节状态：可按草稿/待修改/已完成筛选，在每个章节泳道直接改状态；保存成功后同步正文区当前章节和章节列表，不新增重复状态字段。
- 场景规划板新增叙事顺序时间线：复用章节顺序、场景 `sort_order` 与现有 `when` 自由文本；按章分组展示时间标签、剧情作用、出场人物和钩子；时间线只读排序，重排仍使用原有拖放规划板，未安排场景单独列出。
- 增强 AI 引用推荐：本地展示可解释命中理由（正文/选区、人物/地点/势力别名、标签、当前章关联），别名随角色与世界资料一并带入引用，理由随中英文界面切换；重复引用标记为“已添加”，推荐不会自动进入上下文。
- 打通规划到起草：已关联章节的场景卡提供「用 AI 起草」入口；保存并切换到目标章节、打开 AI 面板、将细纲作为可见引用、预填可编辑请求。未关联章节的场景禁用该入口；不会自动发送或写入正文。
- 补齐 AI 回复来源与修订核验：复用消息上下文快照显示每条回复的来源 chip；可打开请求时快照，并跳回来源章节或故事资料；尝试采纳时阻止跨章节误写，章节修订号变化则二次确认。
- 补齐引用资料版本核验：请求快照记录故事资料卡版本；资料被修改、软删除或缺失时，历史回复显示状态；采纳前重新核对并要求作者确认，原始请求快照仍可查看。
- 支持组合多张写作技法卡：作品级保存最多 6 张卡；服务器按当前写作任务筛选适用技法并合并去重基础规则；管理面板显示本任务真正注入的规则，自定义卡可单独配置续写、润色、自然化润色和构思/起草任务。
- 允许作者保存、编辑、应用和删除自定义多卡技法组合；组合在本机不同作品间复用，删除某张自定义卡时同步从组合中移除，不影响其他卡或作品正文。
- 增加多卡组合 JSON 导入/导出：文件校验格式版本、卡数、任务白名单、字段长度与文件体积；组合里的内置卡按稳定 ID 复用本机当前版本，自定义卡始终导入为新卡，不覆盖现有内容；导入只新增组合，不自动替换当前作品选择。
- 补充自定义技法卡迁移：可将单张自定义卡导出为带格式版本的 JSON 文件，并在其他作品/设备导入为新卡；导入时限制文件体积、字段长度和任务类型，不覆盖现有卡或内置卡。
- 增强人物全书出场核对：沿用现有本地扫描，按卷章顺序列出人物名/别名的命中次数与上下文片段；作者可点击跳回章节。界面明确提醒子串匹配可能误报；长书命中列表只展示最近 200 章，汇总仍基于全书。
- 将人物提及升级为本地增量索引：首次查询或人物名/别名集合变化时重建相关章节索引；章节正文版本变化时仅重建变更章节；普通汇总走索引聚合，只有打开详情时才读取最多 200 个章节正文片段。
- 将相同的本地增量索引扩展至地点与势力：复用世界设定分类，支持维护别名、按章统计提及、展示匹配片段并跳回章节；正文和名称集合变化时增量重建，匹配仅作人工核对提示。
- 人物卡新增作者维护的阶段变化记录：可关联章节、填写变化摘要和触发依据；AI 引用人物卡时将这些记录按章节名整理进上下文，不根据名字命中自动推断阶段。
- 新增标准重排版 EPUB 导出：复用整本/当前卷/当前章节范围，生成 OCF ZIP 包、`mimetype`、容器文件、OPF 元数据、导航文档、样式表和逐章 XHTML；不包含封面与插图，界面明确说明当前限制。
- 新增三组一键题材技法组合及两张配套内置卡：现实悬疑突出可追溯证据与生活流程，国风卡强调资料边界及文化元素进入人物选择；组合应用后仍可逐卡编辑。依据 2024 年行业报告提及的悬疑热度、传统文化与类型叙事融合方向整理，不复刻具体作品或作者表达。

## 后续顺序

1. 相关资料检索增强：索引人物卡、设定正文及细纲关键词，解释命中来源并提供章节回链；仅作为待确认候选。
2. 风格卡工作流：已支持组合、任务范围、发送前规则预览，以及单卡/组合 JSON 导入导出；下一步评估多卡组合模板的作者社区分享与反馈闭环。
3. 场景规划与时间线：已有叙事顺序时间线和章节状态；下一步补充 POV/场景标签与可选时间锚点，并评估按章节/场景长度比例缩放显示，确保排序、章节归属与时间信息可相互核对。
4. 设置与编辑器组件统一：逐个整理表单、菜单和空状态，在浅色/暖纸/深色主题下保持一致。
